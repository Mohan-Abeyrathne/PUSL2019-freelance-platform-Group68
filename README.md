# AI Projects and Services Freelancing Platform

Coursework project for **PUSL2019 – Information Management & Retrieval**.

## Overview
Web platform connecting clients and organizations with AI freelancers across Machine Learning, Deep Learning, Natural Language Processing, Computer Vision, Generative AI, and Data Analytics.

## Tech Stack
- **Frontend:** HTML5, CSS3, Bootstrap 5
- **Backend:** PHP (MySQLi / PDO prepared statements)
- **Database:** MySQL (3NF normalized schema, constraints, triggers, UDFs, views, stored procedures)
